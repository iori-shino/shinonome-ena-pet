## 安装

1. [下载 ZIP](https://github.com/iori-shino/shinonome-ena-pet/archive/refs/heads/main.zip) 并解压。
2. 将解压后的 `shinonome-ena` 文件夹（含 `pet.json` 和 `spritesheet.webp`）复制到对应目录。
   - Windows：`%USERPROFILE%\.codex\pets\`
   - macOS：`~/.codex/pets/`
   - 如果设置了 `CODEX_HOME`，请复制到该目录下的 `pets` 文件夹。
3. 在 Codex 桌面端打开「设置 → Mini 与桌宠（Mini & Pets）」，刷新列表并选中 **Shinonome Ena**。在聊天里输入 `/pet` 即可显示桌宠。

也可以在 ChatGPT Work 中启用 **Pets** 插件，附上 `spritesheet.webp`，请它创建名为 **Shinonome Ena** 的自定义桌宠并启用。
